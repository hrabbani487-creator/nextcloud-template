Nextcloud & MariaDB Stack (Developed by Harish)

Template Docker Compose siap pakai (plug-and-play) untuk mendeploy Nextcloud, MariaDB 10.11, dan phpMyAdmin secara bersamaan. Dikonfigurasi menggunakan port 8080 untuk Nextcloud dan port 8082 untuk phpMyAdmin dengan kredensial default untuk kemudahan pengujian dan penggunaan cepat.
